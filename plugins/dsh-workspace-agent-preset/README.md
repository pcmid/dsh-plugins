# @pcmid/dsh-workspace-agent-preset

按工作区设置默认的 Agent 预设：在某个工作区打开的新会话，默认使用为该工作区选的预设，不再一律使用全局默认。

## 用法

在侧边栏的工作区标题上右键，或点它的「…」按钮，菜单里多了一项 **Agent 预设**。鼠标移上去，右侧展开预设列表：

- **跟随全局默认（…）**：不单独设置，新会话使用全局默认预设。括号里是当前的全局默认。
- 其下是当前可用的各个预设。

当前生效的选项后面有一个勾。选中后立即保存，并提示「『工作区』中的新会话将使用……」。

如果此时正停在这个工作区的空白新会话上，它会一起切换到新选的预设，和 Harness 修改全局默认时的做法一致。

## 行为说明

- **只影响没有指定预设的新会话。** 在新会话页的预设选择器里手动选的预设、创造模式、重启后恢复的空白草稿都会带着各自的预设，不受这里影响；已经开始的会话也不受影响。
- **回到工作区的空白草稿时同样生效。** 在工作区点「新会话」会复用该工作区里还没发送的空白草稿；Harness 原本会把它重置为全局默认，装了本插件后重置为工作区的预设。
- **预设不可用时退回全局默认。** 为工作区选的预设被删除或加载失败时，新会话照常创建，使用全局默认，Host 日志里记一条警告；菜单里该项显示为「（不可用）」。
- **开发者工具关闭时**，PTC 和 Minimal 两个内置预设不在列表里，和 Harness 的预设选择器一致；已经为工作区选了它们的除外。
- **配置按工作区目录保存**，写在 profile 的用户补丁层里本插件那一行的 `workspaces` 下（目录 → 预设 id）。删除工作区不会清掉这一项，之后在同一目录重新添加工作区会继续使用它。也可以直接编辑：

  ```yaml
  - id: workspace-agent-preset
    name: '@pcmid/dsh-workspace-agent-preset'
    config:
      workspaces:
        /Users/me/projects/foo: ptc
  ```

## 已知限制

- **替换了 Harness 的内部方法。** Harness 在创建会话时把「没有指定预设」直接解析为全局默认，中间没有扩展点，所以本插件在实例上替换了 `sessionController.create`：请求没带预设、且所在工作区设置了预设时补上它，再交给原方法；卸载时还原。如果以后 Harness 改了这个方法，插件会记一条警告，工作区预设不再生效，其他功能不受影响。
- **勾的位置靠 CSS 实现。** 右键菜单的数据接口只支持在文字前面放图标，所以勾作为图标传入，再用 CSS `:has()` 把它挪到文字后面。如果以后菜单结构变了，勾会退回到文字前面，功能不受影响。读屏软件读不到哪一项被选中。
- **文案只有中文和英文**，其他语言显示英文；内置预设的名称沿用 Harness 自带的多语言文案。
- **没有提供给 agent 的工具。** 只能在工作区菜单里修改，或手动编辑 profile 补丁。
