agent 用 `todo_write` 维护的任务列表，只有它再次调用这个工具时才会变化。连续调用很多工具时，它常常忘了更新，任务面板就一直停在第一项。

这个插件在列表还有未完成项、而 agent 连续多步没有更新时，给它发一条提醒，附上当前完整的列表。如果列表仍然准确，agent 可以忽略提醒继续工作。

## 设置

在下方修改，保存后立即生效，不需要重启。

- **提醒前的步数**（默认 5）和 **提醒前的工具调用次数**（默认 10）：两个条件先满足哪个就按哪个提醒。每一步最多提醒一次，提醒之后重新计数。
- **回合结束时完成剩余任务**（默认关闭）：回合正常结束时，把剩下的任务标为已完成。agent 停下来报告失败或提问时，没做完的任务也会被标为完成，所以默认关闭。

## 什么时候不提醒

- 当前回合还没有任务列表，或列表已经全部完成。新回合开始时列表会清空。
- 这一步刚更新过列表，或者调用了向用户提问的工具。
- 插件是在回合进行中才加载的：要等 agent 下一次更新列表后才开始计数。

提醒用英文写给模型，在对话里显示为一条可折叠的提示，摘要形如“Todo list 1/3 completed · 当前任务”。
